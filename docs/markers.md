# Key markers (initial)

These are good initial weekly-trend markers for CBC / oncology monitoring:

- Platelets (PLT)
- WBC
- ANC (absolute neutrophil count)
- Hemoglobin (HGB)

We can add:
- RBC, HCT
- Magnesium, random glucose, CRP, lipase
- Lymphocytes
- LDH
- Any flags/notes if the source includes them
